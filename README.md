## Ground rules

1. **All work is in English.** Code, comments, commit messages, branch names, PR titles and descriptions, and documentation.
2. **Every change goes through a Pull Request (PR).** Nobody pushes directly to `main` or `develop`.
3. **The project lead (carrenoA) approves every PR.** Wait for approval before you continue or merge. If changes are requested, fix them in the same branch and wait again.
4. **Always branch from `develop`**, never from `main`.
5. **Always check that the base branch of your PR is `develop`.**
6. **If you are not sure about something, ask before you commit.**

Maintained by the Penguin Foundation team. Project lead: **carrenoA**.
